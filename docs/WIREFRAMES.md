# JTravel — 화면 와이어프레임 (Wireframes)

> [MVP_DESIGN.md](./MVP_DESIGN.md) §2의 UI 컴포넌트 구조를 화면 목업으로 시각화합니다.

## 인터랙션 노트

| 화면 | 제스처/동작 | 결과 |
|------|------------|------|
| Home | SubmitButton 탭 | (2) Loading 진입, URL 무효 시 인라인 에러 |
| Itinerary | SegmentedTab 탭 | List ↔ Map 즉시 전환 (데이터 공유, 스크롤 위치 유지) |
| Map | 마커 탭 | BottomSheet 캐러셀이 해당 카드로 스크롤 동기화 |
| Map | 카드 스와이프 | 지도 카메라가 해당 마커로 이동 |
| Place Detail | 시트 드래그 업 | peek → half → full 스냅 확장 |
| Place Detail | "영상에서 보기" | 타임스탬프로 영상 seek (인앱 플레이어/딥링크) |
| Place Detail | "예약하기" | (5) Reservation WebView |
| 전역 | 뒤로(←) | 이전 화면, 일정은 로컬 자동 저장 |
```
