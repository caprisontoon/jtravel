# 직접 실행하기 — 윈도우 노트북 + 아이폰 가이드 🛠️

> 목표: 내 윈도우 노트북에서 앱을 켜고, **내 아이폰으로 실제 앱처럼** 화면을 보는 것.
> 개발 경험이 없어도 순서대로만 따라오면 됩니다. 예상 30~40분 (처음 한 번만).

---

## 준비물
- 윈도우 노트북
- 아이폰
- 노트북과 아이폰을 **같은 Wi-Fi**에 연결 (이게 중요해요!)

---

## STEP 1. Node.js 설치 (앱을 돌리는 엔진)

1. 노트북 브라우저에서 👉 **https://nodejs.org** 접속
2. **"LTS"** 라고 적힌 큰 버튼 클릭 → 설치 파일 다운로드
3. 다운로드한 파일 실행 → **계속 "Next" 만 누르면 됨** (옵션 건드릴 필요 없음)
4. 설치 끝!

**확인하기:** 시작 메뉴에서 `PowerShell` 검색 → 열고 아래 입력 후 Enter
```
node -v
```
👉 `v22.x.x` 처럼 숫자가 나오면 성공 ✅ (안 나오면 노트북 재시작 후 다시)

---

## STEP 2. 코드 내려받기

> 깃(Git)을 모르셔도 됩니다. **ZIP 다운로드**가 제일 쉬워요.

1. 브라우저에서 GitHub의 내 저장소 접속
   👉 `https://github.com/caprisontoon/jtravel`
2. 화면에서 브랜치를 **`claude/youtube-travel-app-mvp-leyfjo`** 로 변경
   (보통 좌측 상단 `main` 이라고 적힌 드롭다운을 눌러 선택)
3. 초록색 **`Code`** 버튼 → **`Download ZIP`** 클릭
4. 다운로드된 ZIP 파일을 **압축 해제** (오른쪽 클릭 → "압축 풀기")
5. 폴더 이름을 기억해두세요. 예: `다운로드\jtravel`

---

## STEP 3. 앱 부품 설치 (npm install)

1. 압축 푼 **폴더 안**으로 들어가요
2. 폴더 빈 공간에서 **`Shift + 마우스 오른쪽 클릭`** → **"여기서 PowerShell 창 열기"** 선택
   (안 보이면: PowerShell을 따로 열고 `cd ` 입력 후 폴더를 창에 끌어다 놓기)
3. 아래 입력 후 Enter (2~5분 걸려요, 글자가 쭉 올라갑니다)
```
npm install
```
👉 끝나고 다시 입력 줄이 나오면 성공 ✅
(중간에 노란 경고(warning)는 무시해도 됩니다. 빨간 error 가 많으면 알려주세요.)

---

## STEP 4. 앱 켜기 (npm start)

같은 PowerShell 창에서:
```
npm start
```
👉 잠시 뒤 **큰 QR코드**가 화면에 나타나면 성공 ✅ (이 창은 켜둔 채로 두세요)

---

## STEP 5. 아이폰으로 보기 📱

1. 아이폰 **App Store**에서 **`Expo Go`** 검색 → 설치
2. 노트북과 아이폰이 **같은 Wi-Fi** 인지 다시 확인
3. 아이폰 **기본 카메라 앱**을 열어 노트북 화면의 **QR코드를 비춤**
4. 화면 위에 뜨는 알림(배너) 탭 → **Expo Go** 로 열기
5. 잠깐 로딩 후 👉 **내 아이폰에 JTravel 앱이 뜹니다!** 🎉
   - 홈 → "일정 만들기" → 분석 로딩 → 일정/지도 → 장소 상세 → 예약까지 **실제로 눌러서 이동** 됩니다
   - (단, 진짜 유튜브 분석은 아직 샘플 도쿄 데이터로 동작해요)

---

## STEP 6. 글자 하나 바꿔보기 (재미 + 원리 이해)

진짜 내 앱이라는 게 실감 나는 단계예요.

1. 폴더에서 `src\screens\HomeScreen.tsx` 파일을 **메모장**이나 VS Code로 열기
2. `유튜브 링크로\n여행 일정 만들기 ✈` 라는 문구를 찾아 원하는 말로 바꿔보기
3. 저장
4. 👉 아이폰 화면이 **자동으로 바로 바뀜** (이걸 "핫 리로드"라고 해요)

이 원리로 화면 글자·색·구성을 조금씩 직접 고칠 수 있어요.

---

## 🎨 Claude로 만든 디자인을 앱에 넣고 싶다면

디자인을 Claude로 작업 중이라고 하셨죠. 두 가지 방법이 있어요.

- **방법 1 (쉬움):** Claude가 만든 디자인의 **색상 코드(예: #0B7285)** 만 가져와서
  `src/theme/index.ts` 파일의 `colors` 부분을 바꾸면 앱 전체 색이 한 번에 바뀝니다.
- **방법 2 (제대로):** 바꾸고 싶은 화면의 Claude 디자인을 **저(claude code)에게 캡처/설명과 함께 주세요.**
  그 디자인에 맞게 화면 코드를 다시 만들어 드릴게요.

> 팁: Claude로 디자인할 때 "React Native 컴포넌트 코드로 만들어줘"라고 하면
> 이 프로젝트에 바로 붙이기 쉬운 결과가 나와요.

## 자주 막히는 곳 (체크리스트)

| 증상 | 해결 |
|------|------|
| `node -v` 가 안 됨 | 노트북 재시작 후 다시 / Node.js 재설치 |
| `npm install` 빨간 에러 | 인터넷 연결 확인, 폴더 안에서 실행했는지 확인 |
| QR 찍어도 안 열림 | 노트북·아이폰 **같은 Wi-Fi** 인지 확인 (제일 흔한 원인) |
| 그래도 안 됨 | PowerShell 창에 `npm start -- --tunnel` 입력해보기 |
| 앱이 빨간 화면(에러) | PowerShell 창의 메시지를 복사해서 저에게 보여주기 |

---

## 한 장 요약

```
Node.js 설치 → 코드 ZIP 다운 → npm install → npm start
   → 아이폰 Expo Go로 QR 스캔 → 내 앱 확인! 🎉
```

막히는 지점이 생기면 **그 화면을 캡처해서** 저에게 보여주세요. 거기서 이어서 도와드릴게요.
