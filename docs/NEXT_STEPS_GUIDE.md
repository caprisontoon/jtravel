# 비개발자를 위한 다음 단계 가이드 🧭

> "설계와 화면 미리보기까지 마쳤어요. 이제 진짜 앱을 만들려면 뭘 해야 하죠?"
> 개발 용어를 최대한 빼고, 사장님/기획자 입장에서 정리한 안내서입니다.

---

## 1. 지금 내 손에 있는 것 (이미 완료 ✅)

집 짓기에 비유하면 **설계도면과 모델하우스 견본**까지 나온 상태예요.

| 자산 | 파일 | 쉽게 말하면 |
|------|------|------------|
| 기획서 | `docs/MVP_DESIGN.md` | 앱이 무슨 기능을, 어떻게 동작하는지 |
| 화면 설계 | `docs/WIREFRAMES.md` | 화면이 어떻게 생겼는지 (글자 버전) |
| 화면 미리보기 | `docs/preview.html` | 실제로 눈으로 보는 견본 화면 |
| 앱 뼈대 코드 | `src/` 폴더 전체 | 개발자가 이어서 살을 붙일 출발점 |

👉 **이 4가지는 그대로 개발자에게 넘기는 "발주 자료"가 됩니다.** 처음부터 설명할 필요 없이 이걸 보여주면 됩니다.

---

## 2. 진짜 앱으로 만드는 3가지 방법

본인 상황(예산·시간·관여도)에 맞게 고르면 됩니다.

| 방법 | 누가 만드나 | 예상 비용(참고치) | 기간(참고치) | 추천 대상 |
|------|------------|------------------|-------------|-----------|
| **A. 프리랜서 개발자** | 1~2명 외주 | 1,000만~3,000만 원 | 2~4개월 | 예산 절약, 직접 챙길 수 있는 분 |
| **B. 앱 개발 에이전시** | 회사가 통째로 | 3,000만~8,000만 원+ | 3~6개월 | 빠르고 안정적으로, 신경 덜 쓰고 싶은 분 |
| **C. 직접 학습/노코드** | 본인 + AI 도구 | 거의 무료~소액 | 사람마다 | 시간 많고 배우고 싶은 분 |

> ⚠️ 비용·기간은 **참고용 범위**예요. 기능 범위, 디자인 완성도, 지역(국내/해외)에 따라 크게 달라집니다.
> 이번 MVP는 "로그인·결제 없음"이라 일반 앱보다 **가볍고 저렴한 편**에 속합니다.

### 가장 흔한 추천: A안 (프리랜서)
이 정도 규모의 MVP는 **React Native(우리가 쓴 기술) 가능한 프리랜서 1명**이면 충분히 만들 수 있어요.
- 찾는 곳: 위시켓, 크몽, 프리모아 (국내) / Upwork, Toptal (해외)
- 면접 시 한 문장: *"React Native 기반 MVP인데, 설계서·화면·코드 뼈대가 이미 있고 이어서 개발해 주실 분을 찾아요."*

## 3. 개발 시작 전, 내가 직접 준비해야 할 것 (중요 ⭐)

앱이 외부 서비스(지도·예약 등)와 연결되려면 **계정과 열쇠(API 키)** 가 필요해요.
대부분 본인 명의로 가입해야 하고, 개발자에게 키만 전달하면 됩니다.

| 가입할 곳 | 무엇에 쓰나 | 비용 | 비고 |
|-----------|------------|------|------|
| **Google Cloud (Maps Platform)** | 지도, 장소 검색, 길찾기 | 월 일정량 무료 후 사용량 과금 | 신용카드 등록 필요 |
| **YouTube Data API** | 영상 정보 가져오기 | 무료(한도 있음) | 위 Google 계정에서 함께 |
| **Anthropic (Claude API)** | 영상에서 장소 자동 추출 (AI 핵심) | 사용량 과금 | 결제수단 등록 |
| **Booking / Agoda / OpenTable 등 제휴** | 숙소·식당 예약 연결 | 보통 무료(수수료 정산) | 제휴 신청·승인 필요 (시간 걸림) |

> 💡 **팁:** 제휴 예약(Booking 등)은 승인까지 시간이 걸리니, **개발 시작과 동시에 미리 신청**해 두면 좋아요.

## 4. 내가 곧 결정해야 할 것들 (개발자가 물어볼 질문)

미리 생각해두면 개발이 빨라져요.

1. **출시 대상** — 아이폰 먼저? 안드로이드 먼저? 둘 다? (둘 다 가능하지만 둘 다면 비용↑)
2. **앱 이름 & 로고** — "JTravel"은 임시예요. 정식 이름과 간단한 로고 필요
3. **첫 타깃 여행지** — 전 세계 vs 특정 지역(예: 일본)부터. 좁게 시작할수록 품질↑
4. **수익 모델** — 예약 제휴 수수료? 광고? 우선은 "무료로 사용자 모으기"로 시작 추천
5. **앱스토어 등록** — Apple 개발자 계정($99/년), Google Play 계정($25 1회) 필요

---

## 5. 추천 진행 순서 (로드맵)

```
[1] 화면 견본 확정        ← 지금 여기! (마음에 드신 상태)
        │
[2] 위 3장 계정/제휴 신청 시작 (미리미리)
        │
[3] 개발자 1명 섭외 (A안) + 발주 자료 전달
        │
[4] 1차 개발 (4~8주): 유튜브 분석 + 지도 일정 표시
        │
[5] 베타 테스트: 지인 10~20명에게 써보게 하고 피드백
        │
[6] 보완 후 앱스토어 출시
```

- 💰 **상세 견적 항목표** — 견적 비교할 때 쓰는 기능별 체크리스트
