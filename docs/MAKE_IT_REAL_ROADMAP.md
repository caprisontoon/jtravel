# 진짜로 작동하게 만들기 — 로드맵 🚀

> "화면은 다 만들어서 폰에서 돌아가요. 이제 진짜로 유튜브를 분석하고 지도가 뜨게 하려면?"
> 비개발자 입장에서 단계와 순서를 정리한 문서입니다.

---

## 0. 지금 상태 (정확히 이해하기)

지금 앱은 **"잘 만든 마네킹"** 이에요.
- ✅ 화면, 버튼, 화면 이동 = **진짜로 동작**
- ❌ 속 내용(유튜브 분석 결과, 지도, 평점, 예약) = **미리 넣어둔 가짜 샘플(도쿄 데이터)**

즉, 어떤 유튜브 링크를 넣어도 항상 똑같은 도쿄 샘플이 나와요. 이걸 "진짜"로 바꾸는 게 이제부터입니다.

---

## ⭐ 가장 중요한 개념 1가지 (꼭 이해!)

**API 열쇠(key)는 휴대폰 앱 안에 넣으면 안 됩니다.**

왜냐하면 앱 안에 넣은 열쇠는 누구나 꺼내 볼 수 있어서, 남이 내 Claude/구글 요금을 막 쓰게 돼요.

그래서 중간에 **"작은 서버(backend)"** 가 하나 필요해요.

```
[아이폰 앱]  →  [내 작은 서버]  →  [유튜브 / Claude AI / 구글지도]
                  (열쇠는 여기 보관)
```

- 앱은 서버에게 "이 유튜브 링크 분석해줘"라고 부탁만 함
- 서버가 열쇠를 들고 실제 작업을 한 뒤 결과(JSON)를 앱에 돌려줌

> 우리 코드는 이미 이 구조를 염두에 두고 만들어졌어요.
> `src/services/extractionService.ts` 의 가짜 함수를 → 나중에 "내 서버 주소 호출"로 바꾸기만 하면 됩니다.

---

## 단계별 로드맵 (추천 순서)

### 🟢 Phase 1. 진짜 AI 분석 (이게 앱의 심장 ❤️)
유튜브 링크 → 자막 → Claude AI → 장소 목록(JSON) 까지 진짜로.
1. **Claude API 열쇠 발급** (console.anthropic.com 가입 → 결제수단 등록 → API key 생성)
2. **작은 서버 만들기** (`/analyze` 주소 1개. Claude가 같이 만들어 드림)
3. **앱 연결** — `extractionService.ts` 가 서버를 부르도록 변경
4. ✅ 결과: 아무 여행 유튜브나 넣으면 → 진짜 장소 목록이 뜸

> 💰 비용: Claude API는 쓴 만큼 과금. 영상 1개 분석에 보통 수십~수백 원 수준(테스트엔 부담 적음).

### 🟡 Phase 2. 진짜 지도 보여주기
지금 "지도 영역" 자리표시를 진짜 구글 지도로 교체.
1. **Google Maps 열쇠 발급** (Google Cloud → Maps Platform, 카드 등록)
2. `react-native-maps` 부품 설치 + `MapPlaceholder` → 진짜 지도로 교체
3. ✅ 결과: 장소들이 핀으로 찍히고 동선이 그려짐

> ⚠️ 참고: 진짜 지도는 Expo Go에서 일부 제한이 있어, 이 단계부터는 "개발용 빌드"라는 약간 다른 실행 방식이 필요할 수 있어요 (그때 같이 안내).

### 🟡 Phase 3. 장소 정보 보강 (평점·사진·영업시간)
Claude가 뽑은 장소에 구글의 진짜 평점/사진/주소를 붙임 (Google Places API). 서버에서 처리.

### 🔵 Phase 4. 교통 & 택시 요금
대중교통 경로(구글 Directions) + 택시 예상요금(거리·시간 계산). 서버에서 처리.

### 🔵 Phase 5. 예약 연결
Booking/Agoda/식당 예약 제휴 신청 → 예약 버튼이 진짜 예약 페이지로 연결.
(제휴 승인에 시간이 걸리니 일찍 신청해두면 좋음)

### ⚪ Phase 6. 출시 준비
앱 이름·아이콘, Apple 개발자 계정($99/년), 앱스토어 심사, 베타 테스트.
